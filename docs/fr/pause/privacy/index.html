Politique de confidentialité de BrightPause

Dernière mise à jour : 22 novembre 2026

BrightPause est un rappel de pause pour Windows. Il ne collecte rien sur vous et ne partage rien avec personne. La version du Microsoft Store ne se connecte à aucun réseau. Cette politique couvre la version du Microsoft Store et la version compilée à partir du code source public.

Ce qui reste sur votre PC

BrightPause conserve ces fichiers uniquement sur votre PC :

  • settings.json : vos choix (rythme des pauses, son, thème, langue, raccourcis).
  • history.jsonl : une ligne par pause, avec son heure, son type et si vous l'avez prise, reportée ou ignorée. Ce fichier alimente les totaux du jour et de la semaine dans les réglages.
  • events.log : une ligne chaque fois qu'une pause commence, attend ou se termine, avec la raison (par exemple une app en plein écran, et le nom de fichier de cette app). Il aide à expliquer une pause manquée ou en retard. Il reste sur votre PC, et BrightPause le garde sous 0,5 Mo environ.
  • Votre image de fond, si vous en choisissez une.

La version compilée à partir du code source les garde dans %APPDATA%\io.github.jordanalbayrak.brightpause\. La version du Store les garde dans son propre dossier sous %LOCALAPPDATA%\Packages\, et sa désinstallation les supprime. Vous pouvez supprimer l'un ou l'autre dossier à tout moment.

Microphone

Avec « Attendre pendant les appels » activé, BrightPause demande à Windows si une autre app enregistre depuis un microphone, pour qu'une pause ne commence pas au milieu d'un appel. Il n'enregistre jamais, n'ouvre jamais et n'écoute jamais le microphone lui-même, et il n'apprend rien de l'autre app, sauf qu'elle enregistre.

Réseau

  • La version du Microsoft Store ne se connecte à aucun réseau. Le Store livre ses mises à jour.
  • La version compilée à partir du code source se connecte à GitHub uniquement pour vérifier les mises à jour, quand vous appuyez sur « Vérifier les mises à jour » ou activez les mises à jour automatiques (désactivées par défaut).
  • Un lien vers une source sur un écran de pause s'ouvre dans votre navigateur par défaut quand vous cliquez dessus.

Il n'y a ni compte, ni pub, ni statistiques d'usage, ni rapports de plantage, ni télémétrie, et rien n'est partagé avec qui que ce soit.

Enfants

BrightPause ne collecte aucune information personnelle, de personne, y compris des enfants.

Modifications et contact

Les modifications de cette politique sont publiées sur cette page et dans le code source de l'app, où son historique montre chaque version. Des questions? Ouvrez un ticket sur GitHub.
